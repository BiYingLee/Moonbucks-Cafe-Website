# Moonbucks Cafe Website

## About the Project
Moonbucks Cafe is a coffee cafe website developed as an academic group project using HTML, CSS, and JavaScript.

The website provides users with an online platform to explore coffee beverages, browse the menu, and interact with shopping cart functionality.

## Features
- Homepage displaying cafe information
- Menu page with coffee product listings
- Add to Cart functionality
- Login and Sign Up
- Contact page

## Technologies Used
- HTML5
- CSS3
- JavaScript
